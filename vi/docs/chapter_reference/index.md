# Tài liệu tham khảo

[1] Thomas H. Cormen, et al. Introduction to Algorithms (3rd Edition).

[2] Aditya Bhargava. Grokking Algorithms: An Illustrated Guide for Programmers and Other Curious People (1st Edition).

[3] Robert Sedgewick, et al. Algorithms (4th Edition).

[4] Nghiêm Uý Mẫn (Yan Weimin). Cấu trúc dữ liệu (Bản ngôn ngữ C).

[5] Đặng Tuấn Huy (Deng Junhui). Cấu trúc dữ liệu (Bản ngôn ngữ C++, Tái bản lần thứ 3).

[6] Mark Allen Weiss, dịch bởi Trần Việt (Chen Yue). Cấu trúc dữ liệu và giải thuật trong Java (Tái bản lần thứ 3).

[7] Trình Kiệt (Cheng Jie). Đại thoại cấu trúc dữ liệu (Data Structures in Plain Language).

[8] Vương Tranh (Wang Zheng). Vẻ đẹp của cấu trúc dữ liệu và giải thuật.

[9] Gayle Laakmann McDowell. Cracking the Coding Interview: 189 Programming Questions and Solutions (6th Edition).

[10] Aston Zhang, et al. Dive into Deep Learning.

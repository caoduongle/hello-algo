# Cấu trúc dữ liệu

![Cấu trúc dữ liệu](../assets/covers/chapter_data_structure.jpg)

!!! abstract

    Cấu trúc dữ liệu như một bộ khung vững chắc và đa dạng.
    
    Nó cung cấp bản thiết kế cho việc tổ chức dữ liệu một cách ngăn nắp và có trật tự, để từ đó thuật toán có thể phát huy trọn vẹn sức mạnh.
